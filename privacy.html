Personal Login Helper アプリ概要

プライバシーポリシー

Personal Login Helperは、運営者本人1人が自分のWindows PCで使う個人用アプリです。

Googleから取得するデータと用途

Gmail APIの gmail.readonly だけを使います。この権限はメールボックス全体の読み取りを許可します。実際の処理は、同意先が設定した本人のアカウントかの照合と、本人が利用するサービスの正規ログインに対応するワンタイムコードの取得に限ります。

本人が利用するサービスの、ログイン確認用の特定の通知メール（決まった送信元・件名のもの）だけを読み、コードをそのサービスの公式ログイン画面に入力します。メールIDと受信時刻で送信操作の前後を照合し、今回の候補が1件と確定した場合だけ本文を読みます。本文のコードと有効期限を検証します。Gmail上の送信、削除、ラベル変更は行いません。

ローカルでの保存と保護

Gmailのメール本文、コード、候補メールID、アクセストークンは実行中のメモリで扱い、ファイル、実行ログ、画面記録には保存しません。Gmail OAuthのリフレッシュトークンとクライアントシークレットは、現在のWindowsユーザーの資格情報マネージャーに保管します。ログイン先サービスのID・パスワードも、同じ資格情報マネージャーの別の項目に保管します。初期設定で読み込む認証用JSONは本人のPCだけに一時保存し、設定の確認後に本人が削除します。

照合用の本人Gmailアドレスと秘密値を含まないOAuth設定、専用ブラウザのセッション、実行結果は、Google Driveの同期対象外にある本人のPCの専用フォルダに置きます。実行結果には状態、時刻、件数、確認できた資料の情報などを記録しますが、Gmailのメール本文やコード、パスワード、トークンは含めません。

提供と共有

メール認証で取得したコードは、本人のログインのためにそのサービスの公式ログイン画面だけに送ります。Gmail APIから取得したメール本文、コード、メールID、本人アドレス、OAuth資格情報は、Google Drive、公開サイト、共有フォルダに複製しません。本人が別途保存を許可された資料はGmailデータとは分け、本人が指定した保存先だけで扱います。

Google APIから受け取る情報の取り扱いには、限定使用（Limited Use）要件を含む Google API Services User Data Policy が適用されます。
Google API Services User Data Policy

アクセス解除と削除

運営者はGoogleアカウントの「サードパーティとの接続」からアプリへのアクセスを取り消せます。PCに残る資格情報は、初期設定手順に記載されたアプリ用の項目をWindowsの資格情報マネージャーから削除します。アプリを終了したうえで、専用フォルダにある設定・セッション・実行結果も本人が削除できます。
